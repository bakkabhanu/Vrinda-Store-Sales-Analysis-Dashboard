# Vrinda-Store-Sales-Analysis-Dashboard-Excel
📊 Vrinda Store Sales Analysis Dashboard (Microsoft Excel)
**📌 Project Overview**

Developed an interactive Excel dashboard to analyze Vrinda Store's sales performance for 2022. The project transforms raw sales data into meaningful business insights using data cleaning, Pivot Tables, Pivot Charts, and Slicers.

**🎯 Objectives**
Analyze monthly sales and order trends.
Identify top-performing states and sales channels.
Compare customer purchases by gender and age group.
Build an interactive dashboard for business reporting.

**🛠️ Tools & Skills**
Microsoft Excel
Data Cleaning
Pivot Tables
Pivot Charts
Slicers
Dashboard Design
Business Analysis

**📈 Key Insights**
Women contributed a higher percentage of total sales.
Adults (30–49 years) generated the highest number of orders.
Amazon was the leading sales channel.
Most orders were successfully delivered.
Top-performing states included Maharashtra, Karnataka, Telangana, Tamil Nadu, and Uttar Pradesh.

**📊 Dashboard Features**
Monthly Sales & Orders Analysis
Sales by Gender
Sales by Age Group
Order Status Analysis
Sales Channel Analysis
Top 5 States by Sales
Interactive Filters (Month, Category, Channel)
